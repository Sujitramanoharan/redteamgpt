About RedTeamGPT

An adversarial robustness framework for enterprise LLMs.

The Problem

Enterprise LLMs can be hijacked through their input. Jailbreaks bypass safety rules and prompt injection hides malicious instructions inside content the model reads. Attackers reword attacks to evade naive keyword filters.

How It Works

A lightweight DistilBERT classifier acts as a content firewall, inspecting every prompt before it reaches the LLM and blocking malicious ones. Trained on real jailbreak and benign prompts, it runs on CPU for on-premise deployment.

Performance

ROC-AUC 0.996, recall 0.98 on held-out attacks. The framework also evaluates robustness against reworded (evasion) attacks — the key research contribution.
